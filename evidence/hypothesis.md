# Giả thuyết — viết TRƯỚC khi tìm bằng chứng (5 phút, commit ngay)

> Điền ở guide bước 1.1. Ôn lại: ngày 2 · lab ngày 2.
> Viết **trước** khi đọc dòng data đầu tiên hay hỏi người đầu tiên, để không sửa cho khớp kết quả. Kết quả ngược giả thuyết vẫn đủ điểm nếu số là thật.

- Ngày giờ viết: 27/11/2026, chiều, trước CP1
- Người dùng chính (một vai cụ thể): học viên AI20K vừa nhận repo lab trong ngày, muốn làm đúng và hiểu bài
- **Mình nghĩ:** học viên AI20K gặp khó khi bắt đầu một CP của repo lab vì README / checkpoint không nói rõ CP đó cần đọc file nào, sửa file nào, file nào là khung không được đụng; hậu quả là mất thời gian mò repo, sửa nhầm file, và làm xong không nối được code với bài giảng.
- **Có thể còn cách giải thích khác:**
    - học viên kẹt vì thiếu kiến thức nền (vd chưa hiểu trace, p99), không phải vì không tìm ra file
    - kẹt ở cài môi trường / API key, không phải ở đọc repo
    - README đã đủ rõ, học viên không đọc mà hỏi AI luôn
- **Mình đúng nếu thấy:**
    - phỏng vấn: ≥2/3 người kể được ít nhất 1 lần trong tháng qua mất ≥15 phút mới xác định đúng file cần sửa cho 1 CP, hoặc đã từng sửa nhầm file khung
    - khảo sát: ≥50% người trả lời chọn "≥15 phút" ở câu "lần gần nhất, bao lâu mới biết sửa file nào"
- **Nguồn sẽ dùng** (≥1 nguồn đạt ngưỡng, guide 1.2): [ ] đào data · [x] phỏng vấn ≥3 · [x] khảo sát ≥20 — nguồn chính: phỏng vấn ≥3 học viên ngoài nhóm (L3A/L3B) · nguồn để kiểm lại: khảo sát ≥20 học viên + hỏi 1–2 mentor / lab coach
